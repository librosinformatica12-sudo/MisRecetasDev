# Contributing / Contribuir

Please read the bilingual README before testing or submitting changes.
Lee el README bilingüe antes de probar el proyecto o enviar cambios.

When reporting a problem, include:
- Project Zomboid exact build
- Steps to reproduce
- Relevant `console.txt` excerpt, with private information removed
- Whether the in-game change was actually observed

Al informar de un problema, incluye:
- Versión exacta de Project Zomboid
- Pasos para reproducirlo
- Fragmento relevante de `console.txt`, sin información privada
- Si el cambio se observó realmente dentro del juego
